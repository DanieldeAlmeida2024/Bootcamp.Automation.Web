# Requisitos — Bootcamp.Automation.Web

## Objetivo
Automação de cenários web, incluindo autenticação, com Cypress.

## Requisitos funcionais
- RF01: executar os cenários/exercícios existentes.
- RF02: comunicar resultados e falhas de modo reproduzível.
- RF03: preservar exemplos e dependências didáticos.

## Não funcionais
- RNF01: não registrar credenciais reais.
- RNF02: separar dados de teste, roteiro e integração quando possível.
- RNF03: documentar comandos reproduzíveis.
